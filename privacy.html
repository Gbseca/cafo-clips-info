Política de privacidade

O CAFO clips é um aplicativo local para preparar e enviar vídeos às plataformas que você escolher. Esta política descreve os dados usados pelo aplicativo e por este site informativo.

Dados guardados no seu computador

O aplicativo salva rascunhos, escolhas de publicação, caminhos dos arquivos e histórico de envios em um banco SQLite na pasta local do CAFO clips. Os vídeos e imagens de capa permanecem nos locais escolhidos por você; o aplicativo não mantém cópia deles em um servidor próprio. IDs de aplicativos, segredos e tokens de autorização ficam no Gerenciador de Credenciais do Windows.

Dados enviados às plataformas

Quando você confirma um envio, o aplicativo transmite o vídeo, a capa quando escolhida e os metadados do post diretamente às APIs oficiais dos destinos selecionados. A plataforma recebe e trata esses dados segundo sua própria política. O CAFO clips consulta dados da conta conectada necessários para mostrar destinos, permissões, limites e o andamento da publicação.

Uso e compartilhamento

O CAFO clips não possui servidor de coleta, sistema de anúncios ou telemetria própria. Ele não vende dados pessoais. As informações são compartilhadas apenas com as plataformas escolhidas para autorizar a conta, consultar suas opções e realizar as publicações solicitadas.

Este site

As páginas públicas de apresentação, privacidade e termos não pedem login nem recebem vídeos. Se forem publicadas no GitHub Pages, o GitHub poderá tratar dados técnicos de acesso conforme sua própria política de privacidade. Este site não define cookies de rastreamento próprios.

Controle e exclusão

Você pode desconectar uma conta no aplicativo, revogar o acesso nas configurações da plataforma e excluir os arquivos e o histórico locais. Para apagar rascunhos e histórico em conjunto, feche o aplicativo e remova a pasta %LOCALAPPDATA%\CAFO clips. A exclusão local não apaga publicações já enviadas; gerencie-as na plataforma correspondente.

Contato

Para dúvidas sobre esta política, use o perfil público do responsável no GitHub.
