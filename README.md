# Páginas públicas do CAFO clips

Este diretório contém um site estático de apresentação, privacidade e termos para o cadastro de aplicativos nas plataformas. O aplicativo de postagem continua local; este site não recebe vídeos ou credenciais.

O [TikTok exige](https://developers.tiktok.com/docs/en/getting-started-create-an-app) um endereço oficial do aplicativo desktop, URLs de privacidade e termos, e comprovação de propriedade dos endereços antes da revisão. O [GitHub Pages](https://docs.github.com/en/pages/quickstart) oferece um endereço `github.io` sem custo em um repositório público do plano gratuito.

## Antes de publicar

1. Revise o texto de `privacy.html` e `terms.html` quando o aplicativo mudar. O contato público aprovado aponta para o perfil GitHub `Gbseca`.
2. Publique apenas estes arquivos estáticos em um repositório público separado, para não tornar os arquivos do aplicativo públicos sem necessidade.
3. Configure GitHub Pages para publicar a raiz desse repositório. Use as URLs finais de `index.html`, `privacy.html` e `terms.html` no cadastro TikTok.
4. Quando o TikTok fornecer o arquivo de assinatura para verificação por prefixo de URL, coloque-o exatamente no caminho solicitado e publique novamente. O aplicativo TikTok, suas permissões e a aprovação ainda precisam ser criados pelo titular da conta.

Não há JavaScript, imagens remotas, analytics ou formulários neste site.
